7. OOP — klasa

class User:
    def __init__(self, name, email):
        self.name = name
        self.email = email

    def display(self):
        return f"{self.name} <{self.email}>"

class Admin(User):
    def display(self):
        return "ADMIN " + super().display()

self = instanca. __init__ constructor. Trashigimi: Admin eshte User. super() therret prindin.

Encapsulation: _email konventa “internal”. @property per getter.

class Account:
    def __init__(self):
        self._balance = 0

    @property
    def balance(self):
        return self._balance

classmethod / staticmethod: classmethod merr cls (fabrike). staticmethod nuk merr self — funksion brenda klases.

9. Generator vs liste
