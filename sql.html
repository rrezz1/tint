Query qe duhet t’i shkruash pa Google

JOIN

SELECT u.name, o.total
FROM users u
INNER JOIN orders o ON o.user_id = u.id;

INNER: vetem perputhjet. LEFT: te gjithe users, edhe pa porosi.

SELECT u.id, u.name
FROM users u
LEFT JOIN orders o ON o.user_id = u.id
WHERE o.id IS NULL;

Kjo gjen userat pa porosi. Mesoje — vjen shpesh.

Index, PK, FK, N+1

  • PK identifikon rreshtin. FK lidh tabela.
  • Index e shpejton WHERE/JOIN, e ngadaleson pak INSERT.
  • N+1: 1 query per listen + 1 per cdo rresht. Zgjidhje: JOIN ose select_related.
  • Transaksion: te gjitha ndryshimet ose asnje.
SELECT DATE_TRUNC('month', created_at) AS muaj, COUNT(*)
FROM orders
GROUP BY 1
ORDER BY 1;
