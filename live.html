1. Palindrome

A eshte string palindrome? Injoro hapesirat dhe shkronjat e medha.

def is_palindrome(s):
    t = "".join(ch.lower() for ch in s if ch.isalnum())
    return t == t[::-1]

Edge: string bosh → True. “A man a plan a canal Panama” → True.

2. Dy shuma (Two sum)

Lista numrash, target. Kthe indekset e dy numrave qe japin target.

def two_sum(nums, target):
    seen = {}
    for i, n in enumerate(nums):
        need = target - n
        if need in seen:
            return [seen[need], i]
        seen[n] = i
    return None

O(n) me dict. Fol: “nuk bej dy for te ngulitura nese mundem.”

4. Fshi duplikatet, mbaj rendin

def unique(seq):
    seen = set()
    out = []
    for x in seq:
        if x not in seen:
            seen.add(x)
            out.append(x)
    return out

5. Validim email i thjeshte

Junior: nuk te duhet regex i plote. Kontrollo @ dhe piken pas tij.

def looks_like_email(s):
    if s.count("@") != 1:
        return False
    user, domain = s.split("@")
    return bool(user) and "." in domain and not domain.startswith(".")

8. Gjej max pa max()

def my_max(nums):
    if not nums:
        raise ValueError("lista bosh")
    best = nums[0]
    for n in nums[1:]:
        if n > best:
            best = n
    return best

9. API mini: lista ne memorie

Shkruaje me ze si FastAPI: lista USERS = [], POST shton dict me id, GET kthen listen, GET /id kthen 404 nese mungon.

from fastapi import FastAPI, HTTPException
from pydantic import BaseModel

app = FastAPI()
USERS = []
_next = 1

class UserIn(BaseModel):
    name: str
    email: str

@app.get("/users")
def list_users():
    return USERS

@app.get("/users/{uid}")
def get_user(uid: int):
    for u in USERS:
        if u["id"] == uid:
            return u
    raise HTTPException(404, "not found")

@app.post("/users", status_code=201)
def create_user(body: UserIn):
    global _next
    u = {"id": _next, **body.model_dump()}
    _next += 1
    USERS.append(u)
    return u

10. SQL ne koke, pastaj Python

SELECT u.email, SUM(o.total) AS spent
FROM users u
