Si te debugosh me goje, pastaj 6 gabime klasike

  1. Cfare pret te ndodhe? Cfare ndodh?
  2. A riprodhohet gjithmone?
  3. Lexo mesazhin e plote + stack trace (rreshti i fundit i kodit TEND eshte fillimi).
  4. Izolo: print / logging / breakpoint. Nje ndryshim njehere.
  5. Rregullo, provo perseri, shto test nese mundesh.

TypeError: unhashable type: 'list'

Po e perdor listen si celes dict ose ne set. Celesi duhet immutable: tuple, str, int.

KeyError / NoneType has no attribute

data["user"]["name"] kur mungon celesi. Perdor .get("user") or {} ose kontrollo None.

CORS ne frontend

Browser bllokon request nga origin tjeter. Backend duhet te lejoje origin (FastAPI CORSMiddleware). Nuk eshte “JS i gabuar” gjithmone.

500 ne API, 200 ne Postman

Dallimi: header Authorization, Content-Type, body JSON vs form. Krahason request-et.

Migration dështon

Schema lokale ≠ ajo qe pret kodi. makemigrations + migrate. Mos edito me dore tabelen nese ekipi perdor migrations.

N+1 i ngadalte

Faqja ngadale me 50 users. 1 query per users + 50 per orders. JOIN / select_related.

Fjalori per “si e zgjidhe nje bug”

Ne anglisht (mesoje): “I reproduced it, read the stack trace, added a log around the null, found a missing key in the JSON, added validation and a test.”
