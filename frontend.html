React (avantazh)

Komponent = funksion qe kthen UI. props hyjne nga prindi. state (useState) e dhena qe ndryshon UI. useEffect per fetch pas render.

function Users() {
  const [list, setList] = React.useState([]);
  React.useEffect(() => {
    fetch("/api/users").then(r => r.json()).then(setList);
  }, []);
  return list.map(u => <p key={u.id}>{u.name}</p>);
}

key ne lista. Mos fetch pa array varësish — loop infinit.
