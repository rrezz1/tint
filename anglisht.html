TINT Borek

Borek eshte nderkombetare — mund te pyesin ne anglisht

Fjali te gatshme. Lexoje me ze 3 here.

Open

“I’m an early-career developer. I build web apps with Python on the backend and HTML, CSS and JavaScript on the frontend. I want to grow in a team that does code reviews and ships real features.”

Projekt

“I built a small app where users can [X]. The backend is Python with [Django/FastAPI], data in [Postgres/SQLite], and a simple UI. The hardest part was [Y]. I learned to [Z].”

Zevendeso X Y Z para intervistes. Shkruaji tani ne leter.

Nuk e di

“I haven’t used that in production. My first step would be to read the docs and try a small example. For this problem I would start with [simple approach].”

Mos thuaj vetem “I don’t know.” Shto hapin tjeter.

REST

“REST APIs use HTTP methods: GET to read, POST to create. They’re stateless. I return JSON and proper status codes like 201 for created and 404 if the resource is missing.”

Database

“I use relational databases. A primary key identifies a row, a foreign key links tables. I use JOIN to combine them. An index speeds up lookups on columns we filter often.”

Git

“I work on a feature branch, commit often, open a pull request. If there’s a merge conflict I open the file, keep the correct code, then commit.”

Testim

“Unit tests check one function. Integration tests check the API and database together. Tests give me confidence when I change code.”

Docker

“Docker packages the app and its dependencies so it runs the same on my machine and on the server.”

Paga nese pyesin

“I already discussed this with Miranda. 950 euros is what we talked about. I’m more focused on the stack and how juniors grow here.”

Pyetje per ta

  • “What does the day-to-day look like for a junior on the team?”
  • “Do you use Django, FastAPI, or both?”
  • “How do you do code review and deployments?”
