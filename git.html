Testim

# pytest
def add(a, b):
    return a + b

def test_add():
    assert add(2, 3) == 5

Unit: funksion. Integration: client.test_client() ne FastAPI/Django, status 201. Fixture = te dhena gati. Coverage: sa rreshta testohen, jo cilesia e vetme.

Docker

FROM python:3.12-slim
WORKDIR /app
COPY requirements.txt .
RUN pip install -r requirements.txt
COPY . .
CMD ["uvicorn", "main:app", "--host", "0.0.0.0"]

Image = receta e pjekur. Container = procesi. Compose: web + postgres + volume. Port 5432 ne container, ne host ndoshta 5433.
