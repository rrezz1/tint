FastAPI — mbaje ne kok

from fastapi import FastAPI
from pydantic import BaseModel

app = FastAPI()

class UserIn(BaseModel):
    email: str
    name: str

@app.get("/users/{user_id}")
def get_user(user_id: int):
    return {"id": user_id}

@app.post("/users")
def create_user(user: UserIn):
    return user

Fjalori i shkurter

  • ORM — objekte Python ↔ tabela SQL.
  • Migration — ndryshon schema pa humbur te dhena.
  • Middleware — kod para/pas cdo request (auth, log).
  • Session vs JWT — session rri ne server; JWT eshte token i nenshkruar te klienti.

Django: Model → migrate → view/serializer → urls. Kjo fjali mjafton nese ke bere nje tutorial.
